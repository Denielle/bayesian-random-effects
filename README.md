# Bayesian Random Effects

A Python implementation of Bayesian hierarchical random-effects modeling for parameter estimation and uncertainty quantification using observations from multiple data sources.

The package will support user-defined forward models and a custom Metropolis-within-Gibbs sampler, allowing source-specific parameters to be estimated within a shared hierarchical statistical framework.

# Project Status
Under active development.

# Background
This project builds on the statistical methodology and MATLAB implementation developed in:

Ricciardi, D. E. (2020). Uncertainty Quantification and Propagation in Materials Modeling Using a Bayesian Inferential Framework. Ph.D. dissertation, The Ohio State University.

# Planned Features
Support for observations from multiple independent sources

User-defined forward models

Hierarchical random-effects inference

Blockwise Metropolis–Hastings and Gibbs sampling

Posterior summaries and predictive uncertainty

Reproducible examples and automated tests
